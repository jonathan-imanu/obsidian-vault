Thinking about the rules a little bit more would have prevented the first couple wrong submissions. I initially wrote:

```python
class Solution:
	def maxPathSum(self, root: Optional[TreeNode]) -> int:
		def dfs(node):
			if not node:
				return 0, float('-inf')
			
			left_through, left_best = dfs(node.left)
			right_through, right_best = dfs(node.right)
			
			through = max(left_through, 0) + max(right_through, 0) + node.val
			best = max(left_best, right_best, through)
			
			return through, best

return max(dfs(root))
```

The issue with this is that we'll overcount. The path sum can only split at one place: the top-most node from where the maximum path sum starts. This solution allows it to split multiple times breaking the rules.

This means that we should change of recursive solution slightly to account for this. Instead of propagating the best sum through that point that could split (`through`), let's just remove the splitting aspect. 

```python
class Solution:
	def maxPathSum(self, root: Optional[TreeNode]) -> int:
		def dfs(node):
			if not node:
				return 0, float('-inf')
			
			left_gain, left_best = dfs(node.left)
			right_gain, right_best = dfs(node.right)
			
			through = max(left_through, 0) + max(right_through, 0) + node.val
			best = max(left_best, right_best, through)
			
			# doesn't care about splits anymore
			gain = max(0, left_gain, right_gain) + root.val
			
			return gain, best

		return max(dfs(root))
```
