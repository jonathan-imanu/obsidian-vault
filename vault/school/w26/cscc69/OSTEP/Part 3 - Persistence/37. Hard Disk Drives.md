*The main form of persistent data storage in computer systems*.
## Interface

Can be viewed as an array of a large number of sectors (512-byte blocks), each of which can be read or written.
- The sectors are numbered from 0 to $n - 1$ on a disk with $n$ sectors. This is called the **address space** of the drive.

Multi-sector operations are possible but only single 512-byte write is atomic.
- **Torn Write**:  Only a portion of a larger write may complete if power goes out untimely.
### Components of a Disk Drive: Platter

A rotating circular hard surface on which data is stored persistently by inducing magnetic changes to it. 
- A disk can have one or more platters
	- **Surface**: A platter has two sides, each one is called a surface.
- All platters are bound together around the spindle

**Track:** Encoded data on each surface in concentric circles of sectors

**Disk Head**: A mechanism that allows us to read the magnetic patterns on the disk or to induce a change (write) in them. 
- There is a head per surface of the drive.
- Attached to a single **disk arm** which moves across the surface to position the head over the desired track
#### Rotational Delay

The time required for the disk to rotate so that the desired sector aligns under the read/write head after the **seek operation** is complete
#### Seek Time

The time in takes for a disk arm to move to the correct track on surface. 

Has many phases: 
1. An acceleration phase as the disk arm gets moving
2. coasting as the arm is moving at full speed
3. deceleration as the arm slows down
4. settling as the head is carefully positioned over the correct track

**Transfer**: The final phase of disk I/O - when data is read or written to or from the surface.
### Components of a Disk Drive: Cache

AKA: track buffer

A small amount of memory (usually around 8 or 16 MB) which the drive can use to hold data read from or written to the disk.

The cache gives the drive a choice for how to conduct writes. The two options are called **write back** or **write through**.
#### Write Back

Acknowledge the write has been completed when it has put data in memory / it's cache.
- Can make the drive appear "faster" 
- Can be bad for applications that require that data be written to disk in a certain order for correctness
#### Write Through

Acknowledge the write has been completed after it has been written to disk
## I/O Time

$T_{I/O} = T_{seek} + T_{rotation} + T_{transfer}$

The rate of I/O is used for comparison between drives and is easily computed from the time: 

$R_{I/O} = \frac{Size_{Transfer}}{T_{I/O}}$ 

There are two common kinds of I/O workloads:
1. **Random Workload**: Issues small reads to random locations on the disk. Important for things like DBMS
2. **Sequential Workload**: Reads a large number of sectors consecutively from the disk, without jumping around. 
## Disk Scheduling

> High cost of I/O means that OS plays a role in deciding order of I/Os issued to the disk

Given a set of I/O requests, the disk scheduler examines the requests and decides which one to schedule next. 
- Scheduler can estimate how long each request will take because it can estimate the seek time and rotational delay of a request. 
- Follows the principle of **Shortest Job First (SJF)**
### SSTF: Shortest Seek Time First

Orders the queue of I/O requests by track and picks requests on the nearest track to complete first.

SSTF is not perfect. 

**Problems**:

1. Drive geometry is not available to the host OS
	1. Host OS just sees an array of blocks
	2. Can be fixed by implementing **nearest-block-first (NBF)** instead 
2. Starvation can happen if there a steady stream of requests to the track closest to the disk head
## Elevator (SCAN or C-SCAN)

> Implementing SSTF-like scheuduling but avoiding starvation

Moves back and forth across the disk servicing requests across the tracks.
- **Sweep**: A single pass across the disk from outer to inner tracks

**Problems**:
- SCAN does not adhere well to the principle of SSTF because it ignores rotation time. 
## SPTF: Shortest Positioning Time First

Based on both seek and rotational delay.
