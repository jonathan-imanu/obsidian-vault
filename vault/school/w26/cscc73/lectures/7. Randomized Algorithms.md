## General

**Typical Requirements**

There is an efficient algorithm $A$ such that for every input $x$,
$$Pr[ A(x) = f(x)] \geq 1 - \delta$$
where the probability is over the random choice of $A$, $\delta$ is called the error probability and $f$ is the correct answer.
## Error Reduction

#### Problem 

- Fix a Boolean function $f$. 
- Let $A$ be an efficient algorithm such that $\forall x, Pr[A(x) = f(x)] \geq \frac{2}{3}$ 
- Construct an efficient $A'$ st. $\forall x, Pr[A'(x) = f(x)] \geq 1 - \delta$ 
### Estimating the mean

Parameterized by $\epsilon > 0$:

**Input**: Access to $r_1, \ldots, r_N \in [0, 1]$
**Output**: $v \in [0, 1]$ such that $|E_{i \in [N]}[r_i] - v| \leq \epsilon$ 

$E_{i \in [N]}[r_i] = \frac{1}{N} \sum_{i=1}^{N} r_i$ is simply the average of the $N$ points.
#### Theorem 1.

**For every $\epsilon(n) > 0$ there is a probabilistic algorithm solving the problem in time $O(\log(1 \backslash \delta) \backslash \epsilon^2)$ and with error probability $\delta$.**

The algorithm samples $t = O(O(\log(1 \backslash \delta)) \backslash \epsilon^2)$ values in the input $x_{i_1} , \ldots, x_{i_t}$,
and outputs the average of the sample $E_j \in [t][x_{i_j}] = \frac{1}{t} \sum_{j \in [t]} x_{i_j}$

By a suitable law of large numbers (e.g., a Chernoff bound), with probability at least $1 − \delta$ over choice of $x_{i_1}, \ldots, x_{i_t}$ , the average of the sample is $\epsilon$-close in absolute distance to the average of all $N$ values in the input $x$.
#### Theorem 2.

**For every $\epsilon \leq \frac{1}{6}$, every deterministic algorithm solving the problem runs in time $\Omega(N)$ .**

We will demonstrate that every algorithm must read more than $\frac{1}{3}$ values. Proving this will show the lower bound holds.

Let $A$ be some algorithm that solves the problem. To the contrary, suppose that $A$ does this even though it makes less than $\frac{N}{3}$ queries to the input. 

Suppose that on every read done by $A$, we fix the value read $x_{i_j}$ to be 1. So there are $n \leq \frac{2N}{3}$ values that are fixed to 1. 

Call the output of $A$ as $v$. We have two cases:
- If $v \leq \frac{1}{2}$ then we can fix all remaining values not read by $A$ to be 1. Then the mean is 1 and $1 - \frac{1}{2} > \frac{1}{6}$
- Otherwise, let's fix all remaining values not read by $A$ to be 0. Then mean is at most $1/3$ so the distance between $v$ and the actual mean is at least $\frac{1}{2} - \frac{1}{3} = \frac{1}{6}$

## Communication Problems

**Input**: Alice get's $x \in \{0, 1\}^n$ and Bob gets $y \in \{0, 1\}^n$ 
**Output:** 1 if $x = y$; 0 otherwise

BUT Bob and Alice don't know each other's inputs! They must communicate!

### Definition

$\pi(x, y)$ is the **transcript** of the protocol on input $(x,y)$. That is the sequence of messages that were exchanged between Alice and Bob. 
- The "protocol is our algo."
### Lemma: Error-Correcting Codes

For every integer $n$ there is a function Enc: $\{0,1\}^n$ → $\{0,1\}^{2n}$ such that for every $x, y \in \{0,1\}^n$ satisfying $x \neq y$, $\left| \{ i : \text{Enc}(x)_i \neq \text{Enc}(y)_i \} \right| \geq \frac{2n}{100}$ 
- The encodings for $x$ and $y$ differ in at least $\frac{2n}{100}$ positions
### Lemma: Rectangle Property

Let $(x,y)$ and $(x',y')$ such that $\pi(x,y) = \pi(x',y')$. Then, $\pi(x,y) = \pi(x’,y) = \pi(x,y') = \pi(x',y')$
### Theorem 1.

**There is a probabilistic communication protocol solving the problem with $O(\log n)$ communication bits and with error probability 1/10 .**

1. Both parties locally compute Enc(x) and Enc(y). 
2. Alice chooses $t = O(1)$ coordinates $i_1, ..., i_t \in [2n]$, and sends $i_1, \ldots, i_n$  along with $Enc(x)_{i_1} , \ldots, Enc(x)_{i_t}$ to Bob. 
3. Bob checks that $Enc(y)_{i_j} = Enc(x)_{i_j}$ for all $j \in [t]$, and outputs “equal” if and only if all the t checks pass.

The number of bits sent is $t \cdot log(2n) = O(log n)$
### Theorem 2.

**Any deterministic communication protocol solving the problem requires n bits of communication.**
## Finding Prime Numbers

- **Input:** an integer $N$, represented with $n = \lceil log(N) \rceil$ bits  
- **Output:** a prime $p \in [N, 2N]$
### Theorem

**The density of primes in the interval $[N, 2N]$ is at least $1/O(n)$**

**There is a probabilistic algorithm that runs in time $poly(n) = polylog(N)$ and finds a prime number, with error probability $1/10$**
## Connectivity in a Graph

We want to determine connectivity in a graph without using a lot of memory.
### Lemma - Random Walks

Fix a graph $G = ([n], E)$, and let $s \in [n]$ and $t \in [n]$. Consider the following "random walk" procedure, starting at $v_0 = s$:
- for $i = 1, \ldots, O(n^4)$, let $v_i$ be a random neighbour of $v_{i - 1}$

Then, if $s$ and $t$ are connected with probability at least .99 the procedure will encounter $v_i = t$ for some $i$.
### Algo.

For undirected graphs, we can solved connectivity deterministically using $O(log n)$ bits of memory.

## Fingerprinting Lemma

### Setup

Let $x, y \in {0,1}^n$. We want to test whether $x = y$ using randomness. Pick a random vector $r \in {0,1}^n$ uniformly, and compute inner products modulo 2:

$$\langle r, x \rangle = \sum_{i=1}^n r_i x_i \pmod{2}$$
### Lemma (Fingerprinting)

For any $x, y \in {0,1}^n$:
- If $x = y$, then $\langle r, x \rangle = \langle r, y \rangle \quad \text{always}$
- If $x \neq y$, then $\Pr_r\big[\langle r, x \rangle = \langle r, y \rangle\big] = \frac{1}{2}$

### Proof

If $x = y$, the statement is trivial.
Assume $x \neq y$. Define:

$$

z = x \oplus y

$$

where $\oplus$ is bitwise XOR. Then $z \neq 0^n$. Observe:

$$

\langle r, x \rangle = \langle r, y \rangle

;\Longleftrightarrow;

\langle r, x \oplus y \rangle = 0

;\Longleftrightarrow;

\langle r, z \rangle = 0

$$

Since $z \neq 0^n$, there exists some index $j$ such that $z_j = 1$. Now pair every vector $r$ with $r’$ obtained by flipping the $j$-th bit of $r$. Then:

$$

\langle r’, z \rangle = \langle r, z \rangle + z_j \pmod{2}

$$

Since $z_j = 1$, this becomes:

$$

\langle r’, z \rangle = \langle r, z \rangle + 1 \pmod{2}

$$

Thus, in each pair $(r, r’)$, one gives inner product $0$ and the other gives $1$. Therefore exactly half of all $r$ satisfy:

$$

\langle r, z \rangle = 0

$$

Hence:

$$\Pr_r[\langle r, x \rangle = \langle r, y \rangle] = \frac{1}{2}$$

## Randomized Matrix Multiplication (Freivalds’ Algorithm)

### Problem

Given $A, B, C \in \mathbb{F}^{n \times n}$, decide whether:

$$AB = C$$
### Algorithm

Pick a random vector $r \in {0,1}^n$. Compute:

$$Br,\quad A(Br),\quad Cr$$

Accept iff $A(Br) = Cr$

Each matrix-vector multiplication takes $O(n^2)$ time, so total time is $O(n^2)$
### Correctness

If $AB = C$, then $A(Br) = (AB)r = Cr$ so the algorithm always accepts.

If $AB \ne C$, define $D = AB - C \ne 0$ and check whether $Dr = 0$
    
Under this case, if we can show that:

$$

\Pr_r[Dr = 0] \le \frac{1}{2}

$$
is equivalent to showing that we have a less than $\frac{1}{2}$ chance of outputting a false positive (err)
### Proof

It must be the case that $D \ne 0$ (otherwise $AB = C$), there exists a row $i$ such that $D_i \ne 0$. Then:

$$

(Dr)_i = \langle D_i, r \rangle

$$

By the fingerprinting lemma, we can say that:

$$\Pr_r[(Dr)_i=0] = \Pr_r[\langle D_i,r\rangle=0] \le \frac12.$$
Since $Dr=0$ implies $(Dr)_i=0$,  
$$\Pr_r[Dr=0]\le \frac12.$$

## Contention Resolution

### Problem

We have $n$ processes $P_1, P_2, \ldots, P_n$ that are each competing for access to a single shared DB and can't communicate with each other.

Imagine that time is divided into discrete rounds. *The DB has the property that it can be accessed by at most one process in a single round*. 
- If two or more processes attempt to access it simultaneously, then all processes are "locked out" for the duration of that round. 

We must divide up rounds among the processes in an equitable fashion.
### Algo.

Each process will attempt to access the database in each round with probability $p = \frac{1}{n}$, independently of the decisions of the other processes.
#### How did we arrive at this number?

A general strategy that's applicable to all randomized algorithms can be said to be:
1. Leave $p$ blank and say that we'll fill it later
2. Compute what it means to succeed
3. Find the value that maximize (or minimize) the resulting function
