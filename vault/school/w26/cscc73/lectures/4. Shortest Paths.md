### Setup 

A directed graph $G = (V = [n], E)$ with weighted edges that can be negative; we have a weight function that can be negative $w: E \rightarrow \mathbb{R}$

We want the shortest path $dist(u,v)$.
- BFS doesn't work when the graph has weights
- Dijkstra's doesn't work when weights are negative

We assume the following:

1. The graph is connected and has no self-loops
	- WLOG we can run on the connected components
2. The graph has no negative weight cycles
	- Otherwise the problem becomes non-sensical. We can continue in the cycle forever and always "profit" from doing so.

There are two types of shortest-path algorithms:
1. Single-source: the distance from a node $u$ to another node $v$
2. All-pairs: the distance from every node $u$ to every other node $v$

## Single-Source Shortest Path (SSSP): Bellman-Ford

### Setup

#### Input

A graph $G = (V=[n],E)$, a weight function $w: E \rightarrow R$ and a vertex $s \in [n]$.
#### Output

$(dist(s,v))_{v \in [n]}$
### Idea

- Fix $s \in [n]$. 
- For every $v \in [n]$, let $w^*(v) = dist(s, v)$. 
- For every $v \in [n]$ and $i \in [n - 1]$, let $w^*(v, i)$, be the minimal weight of a path from $s$ to $v$ of length at most $i$.
#### Lemma

For all $v \in [n]$, we have $w^*(v) = w^*(v, n - 1)$.
- "The best path from $s$ to $v$ has at most $n - 1$ edges."

The main recursive formula stems from:
- For every $v \in [n] \backslash \{s\}$ and $i \in [n - 1]$,
	- $w^*(v,i) = min\{ w^*(v, i - 1), min_{u \in V}\{w^*(u, i - 1) + w(u, v)\} \}$ 
- where $w^*(s, 0) = 0$ and $w^*(v, 0)= \infty$ if $v \neq s$    
### Naive

```
def bf-naive(G, w, s):
	let opt[(1,0),...,(n,n-1)] be an empty (n×n)-array
	for every v in [n]:
		if v = s, set opt[v,0] = 0; else opt[v,0] = inf
	for i in [n - 1]:
		for v in [n]:\
			for u in V:
				opt[v, i] = min(opt[v,i-1], opt[u,i-1] + w(u,v))
	return opt[v, n - 1] for v in [n]
```

This has the running time of $O(n^3)$.
- There's waste because we iterate over every vertex even if it's not a neighbour

This inefficiency is present in our recursive formula as well. So we start by fixing that.
### Optimized

Define $N(v)$ to be the set of neighbours of $v$. 

We can now have the following recursive formula:

$$
\text{For every } v \in [n] \text{ and } i \in [n-1],
\qquad
w^*(v,i)
=
\min \left\{
  w^*(v,i-1),
  \min_{u \in N(v)}
  \left\{
    w^*(u,i-1) + w(u,v)
  \right\}
\right\}
$$
From this we can 
```
def bellman-ford(G, w, s):
	let N[1, ..., n] be an array of lists
	for i in [n]:
		for j in [n]:
			if (i,j) in E:
				add j to N[i]
	let opt[(1,0), ..., (n, n - 1)] be an empty (n by n) array
	for v in [n]:
		if v = s:
			opt[v,0] = 0
		else:
			opt[v, 0] = inf
	
	for i in [n - 1]:
		for v in [n]:
			for u in N[v]:
				opt[v,i] = min(opt[v,i-1], opt[u,i-1] + w(u,v))
				
	return opt[v,n-1] for v in [n]
```

This has a running time $O(|V| \cdot |E|)$ 
## All-pairs Shortest Path (ASAP)

**Input:** A directed graph $G = (V = [n], E)$ with weighted edges that can be negative; we have a weight function that can be negative $w: E \rightarrow \mathbb{R}$
- We have no negative cycles, connected and have no self-loops

**Output**: A $n \times n$ matrix describing the weights of the shortest paths in $G$. 
### Idea

We re-weight the graph so that weights are non-negative. We then run Dijkstra from all vertices.

**How to do the reweighting?**

Naively adding some constant $c$ doesn't work because it impacts "longer" (as in more edges) paths far more than shorter ones.
### Re-weighting Lemma

Fix any $h: V \rightarrow R$, let $w'(u,v) = w(u,v) + h(u) - h(v)$. Then:
- a path $P$ is shortest under $w'$ $\iff$ $P$ is shortest under $w$
- a cycle $C$ is negative-wt under w' $\iff$ $C$ is negative-wt under $w$

Defining $h: V \rightarrow R$, add a dummy vertex $s$ (with zero-weight outgoing edges to all $v \in V$), let $h(v) = dist_{w}(s, v)$. 

**Why isn't $h(v) = 0$?**

Because we have negative weights! 

**So what is $h$ actually?**

The *true shortest distance* from the dummy source to $v$.
#### Proof

$w'(u,v) = w(u,v) + h(u) - h(v) \geq 0$, for all $u,v \in V$  

We want:

 $w(u,v) + h(u) - h(v) \geq 0$

Rearranging we get,

$h(v) \leq h(u) + w(u, v)$ which is equivalent to $dist(s, v) \leq dist(s, u) + w(u, v)$

Since $dist(s, v)$ is the shortest path to $v$, any other path must be less than it by definition.
### Recap

- We want to run Dijkstra from every vertex
- We need to re-weight first
	- We'll use the re-weighting lemma to do this
- To re-weight, it suffices to find $dist(s, v), \forall v \in V$ from a single dummy vertex $s$
### The Algorithm 

**TC**: $O(|E| \cdot |V| + |V|^2 \cdot \log(|V|) )$

**Input**: $G, w$

1. Let $G^{B, F}$ be $G$ with an additional vertex $s$ that has outgoing zero-weight edges to all other vertices
2. Run Bellman-Ford on $G^{BF}$ with source $s$, to obtain $h(v) = dist(s, v)$ for all $v \in V$
3. *Reweighting Step* - For every $e = (u, v)\in E$, set $w’(u,v) = w(u,v) + h(u) - h(v)$
4. For each $u \in V$, run Dijkstra's algorithm with source $u$, to obtain $d[u] = (dist(u,v))_{v \in V}$
5. *Reverse the reweighting* - $d[u][v] - h(u)+h(v)), \forall u,v \in V$  
6. Return  $(d[u][v]- h(u)+h(v))$ $\forall u,v \in V$
## Djikstra's Shortest Path

**Input**: 
- $G = (V, E)$ for $V \in [n]$
- $w': E \rightarrow R$
- $s \in [n]$

**Output**: $(dist(s, v), \forall v \in V)$ wehre $dist(s, v)$ is the opt. distance from $s$ to $v$

**TC**: 
- $O(|V| \cdot \log(|V|) + |E|)$
	- Recall that Bellman Ford has TC $O(|V| \cdot |E|)$
