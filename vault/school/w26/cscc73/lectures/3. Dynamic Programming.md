## Weighted Interval Scheduling
### Problem

#### Setup

- For an interval $I \subseteq R$, denote $s(I) = \min_{x \in I} \{ x \}$ and $f(I) = max_{x \in I} \{ x \}$
- A set of intervals $I_1, \ldots, I_n$ is valid if for each $i \neq j \in [n]$  we have $I_i \cap I_j = \emptyset$ 
- For a set of intervals $S = \{ I_1, \ldots I_n \}$ and a weight function $w: S \rightarrow R^+$, the weight of $S$ is $w(S) = \sum_{i \in [n]}w(I_i)$ 
#### Input

- A set of intervals $S = I_1, \ldots, I_n \subseteq R$ and a weight function $w: S \rightarrow R$ 
- We assume that $I_1, \ldots, I_n$ are sorted by ascending finish time
#### Output

- A valid $T \subseteq S$ such that $w(T) = w^*$, where $w^* = \max_{\text{valid } T' \subseteq S} \{ w(T')\}$
### Naive Idea - Backtracking

```
WIS( I1,...,In ):
	if n = 0 return ø // base case
	S1 = WIS( I1,...,In-1 ) // either In isn’t in an optimal solution
	compute the subset T ⊆ { I1,...,In-1 } of intervals that are disjoint from In
	S2 = WIS( T ) U { In } // or In is in an optimal solution
	
	if w(S1) ≥ w(S2) 
		return S1
	return S
```

Based on this naive solution, we can make some observations:
- This algorithm only considers optimal solutions for sets of the form $\{ I_1, \ldots, I_i \}$ for some $i \in [n]$
#### Notation

For every $i \in [n]$,
- Let $p(i) \in \{ 0, \ldots, n\}$ be the interval with maximal finish-time smaller than the start time of $I_i$, or zero if none exists
- Let $w^*(i) \in R$ be the weight of an optimal solution for $I_1, \ldots, I_i$ 
### Lemma 1

Let $T_i^* \subseteq \{I_1,\ldots,I_i\}$ be an optimal solution for $I_1,\ldots,I_i$. Then:

$$
\begin{aligned}
&\text{If } I_i \in T_i^*, \text{ then } T_i^* \setminus \{I_i\} \text{ is an optimal solution for } I_1,\ldots,I_{p(i)} \\
&\text{If } I_i \notin T_i^*, \text{ then } T_i^* \text{ is an optimal solution for } I_1,\ldots,I_{i-1}
\end{aligned}
$$
- Can be proved pretty easily with induction.
#### Corollary

For all $i \in [n]$, $w^*(i) = \max \{ w(I_i) + w^*(p(i)), w^*(i - 1)\}$

### Naive Idea 2 - Better Backtracking

This may led us to this dynamic programming approach:

```
let WIS(i):
	if i = 0, return 0
	return max{ w(Ii) + WIS( p(i) ), WIS( i-1 ) }
return WIS(n)
```

- Almost perfect, but still very inefficient with lots of repeated work.
### DP Impl.

```
let opt[0,...,n] be an empty array

let WIS(i):
    if i = 0:
        opt[0] = 0
        return 0

    for j ∈ { p(i), i-1 }:
        if opt[j] is undefined:
            run WIS(j)

    opt[i] = max{ w(I_i) + opt[p(i)], opt[i-1] }
    return opt[i]

return WIS(n)
```

### Proving Correctness
#### Lemma 2
##### Claim

WIS(i) returns $w^*(i)$ & writes it at `opt[i]`
##### Proof 

By strong induction.
###### Base Case

When $i = 0$, follows from L3.
###### IS

Assume that our claim holds $\forall j < i$ (I.H)

By recursive formula:
- $w^*(i) = max(w(I_i) + w^*(p(i)), w^*(i - 1))$
	- We proved this before. 
	- The key is

By I.H, `opt[p(i)]` = $w^*(p(i))$ and `opt[i - 1]` = $w^*(i - 1)$ after L5 concludes. Hence L6 writes $w^*(i)$ in `opt[i]` and L7 returns it.
#### Lemma 3
##### Claim

$\forall i \in [n]$, WIS(i) is called at most once.
##### Proof

Observe that when WIS(i) is called, the algorithm, including all of the recursive calls only calls WIS with inputs smaller than i. For $i = n$, WIS(n) is only called in L8 and never again. For $i < n$, WIS(i) can only be called in L5. This only happens when `opt[i]` is undefined. But after calling WIS(i) once, `opt[i]` is defined by (by previous lemma). Hence WIS(i) is called at most once.
## Knapsack
### Problem 

#### Setup

- Consider a set $[n]$ of items, weight function $w: [n] \rightarrow N$, and a value function $v: [n] \rightarrow R^+$ 
- For a subset $S \subseteq [n]$ of items,
	- the weight of $S$ is $w(S) = \sum_{i \in [n]}w(i)$
	- the value of $S$ is $v(S) = \sum_{i \in [n]}v(i)$

#### Input

A weight function $w: [n] \rightarrow N$, a bound $W \in N$, and a value function $v: [n] \rightarrow R^+$
#### Output

A set $S \subseteq [n]$ such that $w(S) \leq W$ and $v(S) = v^*$, where $v^* = \max_{T \subseteq [n], w(T) \leq W} \{ v(T) \}$
### Notation

Fixing a value function $v$, for every $i \in [n]$ and $W' \in \{0,\ldots,W\}$,

let $v^*(i, W') \in \mathbb{R}$ be the value of an optimal solution  
for items $[i]$ with weight bound $W'$.

### Lemma (main recursive formula)

For all $i \in [n]$,

$$
v^*(i, W') =
\begin{cases}
\max \{\, v(i) + v^*(i-1, W' - w(i)),\; v^*(i-1, W') \,\} & \text{if } W' \ge w(i) \\
v^*(i-1, W') & \text{otherwise}
\end{cases}
$$

where $v^*(0, W') = 0$ for all $W'$.

Get recursive formula. Prove the recursive formula holds via an exchange argument. THEN correctness of the iterative case it obvious.
### Pseudopolynomial Time

Polynomial in $n$ and the number $W$ which can be thought of as a parameter. $W$ is represented as a binary string of length $\lceil \log_2(W) \rceil$. THEN a real polynomial time algorithm would run in time $poly(n \log W)$.  Thus our proposed algorithm is called pseudo-polynomial time.
