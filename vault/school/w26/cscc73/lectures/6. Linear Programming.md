Our goal is to find $x \in R^n$ that maximizes:
- $c_1x_1 + \ldots + c_nx_n$ 

Constrained by some linear system of $n$ equations:

- $a_{11}x_1 + \ldots + a_{1n}x_n \leq b_1$
- ...
- $a_{n1}x_1 + \ldots + a_{nn}x_n = b_n$

#### Max Flow using LP

Let:
- $G=(V,E)$ be a directed graph
- $s$ be the source
- $t$ be the sink
- each edge $e \in E$ has capacity $c_e \ge 0$
    
Define a variable $f_e$ for each edge $e$. This means: how much flow goes through edge $e$.

**Goal**: Maximize the total flow sent out of $s$: $\max \sum_{(s,v)\in E} f_{sv} \;-\; \sum_{(v,s)\in E} f_{vs}$

Add the following constraints:

1. For every edge $e\in E$, $0 \le f_e \le c_e$
	1. Flow on an edge cannot be negative and cannot exceed its capacity.
2. For every vertex $v \in V \setminus \{s,t\}$, $\sum_{(u,v)\in E} f_{uv} \;=\; \sum_{(v,w)\in E} f_{vw}$
#### Shortest paths using LP

Let:
- $G=(V,E)$ be a directed graph
- Each edge $e \in E$ has cost $c_e \in \mathbb{R}$
- Given a source node $s$ and a target node $t$

We want to want distance from $s$ to all other $v \in V$. Let $d_v$ represent the distance from $s$ to $v$. It follows that $d_s = 0$.

We want to maximize $d_t$. Notice that $d_t$ is less than or equal to the length of **every** path from $s$ to $t$.

Define constraints:
- $d_v$ = $d_u$ + $c_{v,u}$
## Solving LP

Linear programming can be solved in polynomial time; that is in time $(n \cdot m \cdot \log(C)^c)$ for some constant $c > 1$, where $C$ is an upper-bound on the absolute values of all input numbers.
## Geometry of LPs

Given an LP, a vector $x \in R^n$ is **feasible** if it satisfies all inequalities. The **LP is feasible** if there is a feasible vector $x$.

A **polytope** in $R^n$ is defined by a set of linear inequalities over $R^n$. The polytope is the set of points in $R^n$ satisfying all inequalities.

*The feasible solutions for an LP form a polytope.*
### Theorem 2.

If an LP is feasible, and the feasible polytope is contained in a finite-radius ball in $R^n$, then:
1. There is an optimal solution
2. All optimal solution are vertices of the feasible polytope
### Proposition 3

Solving LP reduces to the following problem: **Given a feasible LP, find some feasible solution.**

**Proof**

Let $A$ be an efficient algorithm that, given a feasible LP, finds some feasible solution. Using $A$, we can then decide whether or not a given LP is feasible: Given an LP, run $A$ on it, and then check if the solution returned by $A$ satisfies the LP. 

Let $L$ be a given LP that we want to solve, with $n$ variables and $m$ constraints using coefficients of size at most $C$. Since all feasible solutions for $L$ are contained in a ball of radius $2^{O(n \cdot log(C))}$ around $0^n$, for every feasible $x \in R^n$ we have:
$$\sum_{i \in [n]} c_i \cdot x_i \leq \sum_{i \in [n]} C \cdot |x_i| \leq n \cdot C \cdot 2^{O(n \cdot log(C))}$$
$$ \leq n \cdot C \cdot 2^{O(n \log C)} = 2^{\log n + \log C} \cdot 2^{O(n \log C)}$$
$$= 2^{O(n \log C)}$$
By a symmetrical argument, the optimal value is at least $-2^{O(n \cdot log(C))}$. 

Define $v = 2^{O(n \cdot log(C))}$, so we know that the value of an optimal solution lies within the interval $[-v, v]$. So we can perform **binary search**!

At every iteration $i$, we have the invariant that the optimal solution lies within the interval $[a_i, b_i]$. We add the following constraint to $L$:
$$m_i = \frac{a_i + b_i}{2} \leq \sum_i c_i \cdot x_i \leq b_i$$ and we check if the LP with the additional constraint is feasible using $A$. If it is, we update $a_{i + 1} = m_i, b_{i + 1} = b_i$. Otherwise, we set $a_{i + 1} = a_i, b_{i + 1} = m_i$

We do this for $t = O(\log(v / \epsilon))$ iterations we stop, run $A$ on $L$ with all of the added constraints generated by our algorithm and output the feasible solution that $A$ gives us.
## Ellipsoid Algorithm

### Main Idea

Given a polytope in $R^n$, find a point inside. The feasible polytope is a complicated shape. By wrapping it in a simple ball set, we can easily check if that wrapper set's center is feasible. 
- Main lemma: If the center isn't feasible, we can wrap the feasible polytope by a significantly smaller ball with a new center.
Recurse until our ball wraps the polytope so tightly that its center must be inside.
### Ellipsoid Definition

*Our generalized notion of "a ball"*

An **ellipsoid** in $R^n$ is a set of the form:
$$\{ x \in R^n: (x-p)^T M (x - p) \leq 1\}$$
for $p \in R^n$ and a PSD matrix $M \in R^{n \times n}$ 
- A matrix is PSD (**Positive semidefinite**) if $x^T M x \ge 0 \quad \text{for all } x \in \mathbb{R}^n$ 
#### Facts

1. **We can compute the center of an ellipsoid in polytime**
2. **The volume of an ellipsoid has a closed-form formula that we can efficiently compute**
3. Given an ellipsoid $E$ and a linear function $L$, let $\text{half}_L - E = E \cap \{ x: L(x) \leq L(p) \}$, where $p$ is the center of $E$. **Then we can compute the minimum-volume ellipsoid containing $\text{half}_L -E$ in polytime.**
4. For every $i \geq 0$ we have $Vol(E_{i + 1}) \leq (1 - \frac{1}{2n}) \cdot Vol(E_i)$  
### Algo. Assumptions

1. We are given an ellipsoid $E_0$ that contains the feasible set $S$
2. We are given a lower bound $V_l$ on the volume of $S$
3. Given $p \in R^n$, we can efficiently decide if $p \in S$ and otherwise obtain a linear equality separating $p$ from $S$
#### Lemma

For any feasible LP:
$$V_\ell = 2^{-\Omega(n \cdot \log C)} \quad\text{and}\quad \text{Vol}(E_0) = 2^{O(n \cdot \log C)}$$
### Algo.

```
for i = 0, 1, 2, ... while Vol(E_i) ≥ V_ℓ:
    1. Let p_i = Center(E_i)
    2. Query the separation oracle with p_i
    3. If p_i ∈ S:
           return p_i   // Found a feasible point
    4. Else:
           // Oracle returns a violated inequality L(x) ≤ b
           Define:
           half_L(E_i) = E_i ∩ { x : L(x) ≤ L(p_i) }
           Compute:
           E_{i+1} = minimum-volume ellipsoid containing half_L(E_i)
return "fail"   // No feasible solution exists
```
### Correctness

There are two cases:

**Case 1**: The algorithm returns a feasible point

By definition of feasibility and from the correctness of the separation oracle, this point will satisfy all inequalities.

**Case 2**: The algorithm outputs "fail"

We must show that no feasible solution exists.

## Standard Form

**Input**: Matrix $A \in R^{m \times n}$ and two vectors $b \in R^m$ and $c \in R^n$ 
- $A$: the matrix with $m$ constraints and $n$ variables
- $b$: RHS of the constraints
- $c$: Coefficients of the objective function

**Output**: A vector $x \in R^n$ such that
- $A \cdot x \leq b$
- $c^T \cdot x = v^*$, where $v^* = \max_{x' \text{ st } Ax \leq b} \{ c^T \cdot x \}$ 

### Converting a Minimization Problem to Standard Form

Suppose we want to convert the LP

$$\min \mathbf{1}_n^T y \qquad \text{s.t.} \qquad M^T y \ge \mathbf{1}_m,\quad y \ge 0$$

to standard form.

- We start by turning $\min$ to $\max$ by applying $\max -1_n^T y$
- $M^T y \geq 1_m \iff -M^T y \leq -1_m$ 

so we have 

$A = -M^T, b = -1_m, c=-1_n$

- $c$: Coefficients of the objective function
**Output**: A vector $x \in R^n$ such that 
- $A \cdot x \leq b, x \geq 0$ 
	- THE ONLY DIFFERENT IS $x \geq 0$

## Duality

**Problem**: Given an LP $(A,b,c)$ and a feasible $x$, how can we verify that the optimal value can’t be better than $c^T \cdot x$?
### General Approach

Start with an LP $(A, b, c)$. Let $y \in R^m, y \geq 0$ be a vector specifying a linear combination of the rows of $A$. Then, for every feasible $x \in R^n$, 
$$y^T \cdot A \cdot x \leq y^T \cdot b$$
If we take $y$ such that $c^T \leq y^T \cdot A$, for every feasible $x \in R^n$,
$$c^T \cdot x \leq y^T \cdot A \cdot x \leq y^T \cdot b$$
### Even More General 

- Start with an LP $(A, b, c)$
- Let $y \in R^m, y \geq 0$ be a vector specifying a linear combination of the rows of $A$. Then, for every feasible $x \in R^n$ $y^T \cdot A \cdot x \leq y^T \cdot b$
- If we take $y$ such that $c^T \leq A^T \cdot y$, for every feasible $x \in R^n$: $c^T \cdot x \leq y^T \cdot A \cdot x \leq b^T \cdot y$
### The Goal of a Dual Program

Find $y \geq 0$ such that $c^T \leq A^T \cdot y$  and $b^T \cdot y$ is minimal

For any feasible LP, any feasible value $v^{\text{dual}}$ of the dual LP upper-bounds the optimal value $v$ of the original LP.

An LP is feasible and has an optimal solution if and only if its dual is feasible and has an optimal solution. In this case, the optimal values of the LP and of its dual are equal.

## Nash Equilibrium

- A two-player game is specified by two payoff matrices $A,B \in R^{n \times n}$. 
- A two-player game (A,B) is zero-sum if $A = -B$.
### Definition

A **mixed strategy $\mu$** is a probability distribution over $[n]$. Let $\mu_A$ and $\mu_B$ be mixed strategies for $A$ and $B$. Then the **expected payoffs** for $A$ and for $B$ are:
$$E_{i \sim \mu_A, j \sim \mu_B} [A_{ij}], E_{i \sim \mu_A, j \sim \mu_B} [B_{ij}]$$
where “$i \sim \mu_A , j \sim \mu_B$ ” denotes independent choices of $i$ and $j$.
#### Informal

For a two-player game $(A, B)$, a Nash equilibrium is a pair of mixed strategies $(\mu_A , \mu_B )$ such that:
1. When $B$ uses strategy $\mu_B$ , there is no strategy for $A$ yielding a better expected payoff than $\mu_A$ 
	1. IE $\forall \mu_A', E_{i \sim \mu_A', j \sim \mu_B} [A_{ij}] \leq E_{i \sim \mu_A, j \sim \mu_B} [A_{ij}]$ 
2. When $A$ uses strategy $\mu_A$ , there is no strategy for $B$ yielding a better expected payoff than $\mu_B$ .
### Theorem

Every zero-sum two-player game has a Nash equilibrium. Moreover, given such a game, we can find a Nash equilibrium in polynomial time.
### von Neumann's minimax theorem

**Main Trick**: We can reduce the problem to linear algebra. The prob. distribution over $[n]$ = non-negative unit vector in $R^n$

**Observation**: For any two mixed strategies $x, y$:
- the expected payoff for $A$ is $x^T \cdot A \cdot y$ 
- the expected payoff for $B$ is $-x^T \cdot A \cdot y$

For every $A \in R^{n \times n}$ , $\max_{x \in U} min_{y \in U} \{ x^T Ay \} = min_{y \in U} max_{x \in U} \{ x^T Ay \}$ where $U \subseteq R^n$ is the set of non-negative vectors with $l_1 - \text{norm} 1$.  

Moreover, given such a game, we can find x and y that attain the values above in polynomial time.

## Vertex Cover Problem

### Problem

**Input**: An undirected graph $G = (V, E)$
**Output**: A subset $C$ of $V$, such that every edge $e \in E$ has at least one endpoint in $C$ and $C$ is minimized.

Let
$$ x_i = \begin{cases}
1 & \text{if } v_i \in C \\
0 & \text{otherwise}
\end{cases}$$

We want to minimize $\sum x_i$ 

We want at least one endpoint of each edge in $C$ so we have the constraint $x_i + x_j \geq 1$ if $(v_i, v_j) \in E$ and $x_i \in \{ 0, 1 \}$ . So constraints are:
- $x_i + x_j \geq 1$ if $(v_i, v_j) \in E$
- $x_i \in \{ 0, 1 \}$

BUT recall the complexity of integer LP is NP complete!
### Linear Relaxation

We want to restate ILP as an LP to get an approximate solution in polynomial time. 

**Idea**: Restate this ILP as an LP to get an approximate solution in polytime.

**Objective Function:** Minimize $x_1 + x_2 + \ldots + x_n$.

**Constraints**:
- $x_i + x_j \geq 1$ if $(v_i, v_j) \in E$
- $0 \leq x_i \leq 1, \forall v_i \in V$
