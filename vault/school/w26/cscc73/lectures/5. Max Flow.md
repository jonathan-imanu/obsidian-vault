## Setup 

- A directed graph $G = (V, E)$. 
- We have two special vertices $s$ (the source) and $t$ (the sink / target). 
- Every edge has a capacity $c: E \rightarrow N^+$. 

We want to send a "flow" from $s$ to $t$.
- WLOG there are no anti-parallel edges

A flow is a function $f: E \rightarrow R^+ \cup \{ 0 \}$ satisfying:
- $\forall e \in E$, $f(e) \leq c(e)$ 
	- The flow of a node can't be bigger than it's capacity
- $\forall v \in V \backslash \{ s, t\}, f^{in}(v) = f^{out}(v)$
	- The flow coming in must equal the flow coming out

$⊽(f) = f^{out}(s)$ is the value of a flow. 
### Useful Notation

- $f^{in}(v) = \sum_{\text{ e going into v}} f(e)$ 
 - $f^{out}(v) = \sum_{\text{ e going out of v}} f(e)$ 
 - $f^{in}(S) = \sum_{v \in S} f^{in}(v)$ 
 - $f^{out}(S) = \sum_{v \in S} f^{out}(v)$ 
### Lemma 1 (for $\unicode{x22BD} f$)

- For any flow $f$ we have $f^{out}(s) = f^{in}(t)$ 

Suppose that $\gamma$ is all nodes. THEN

$$f^{in}(\gamma) = f^{in}(V \backslash \{ s \})$$
$$= f^{in}(t) + f^{in}(V \backslash \{ s, t \})$$

We can use this exact same strategy for $f^{out}$ and arrive at $f^{out}(\gamma) = f^{out}(s) + f^{out}(V \backslash \{ s, t\})$

Then we can substitute these expressions in $f^{out}(s) = f^{in}(t)$ and will arrive at 0 which proves the claim.
## The Problem

Given the setup above,

**Input**: A flow network $(G, c, s, t)$
**Output**: A flow $f:E \rightarrow R^+ \cup \{ 0 \}$ of value $\unicode{x22BD} (f) = v^*$ where $v^* = \max_{\text{flow f'}}\{ \unicode{x22BD}(f')\}$   

## The Naive Greedy Algorithm

### Idea

Find a $s \rightarrow t$ path on which we can increase the flow, and increase the flow through it as much as we can. Repeat until there's no such path left.

$$
\begin{aligned}
&\textbf{Input: } G, c, s, t\\
&1.\ \text{let } f \equiv 0\\
&2.\ \text{while there is an } s \to t \text{ path } P \text{ such that } \forall e \in P,\ f(e) < c(e):\\
&\qquad \text{let } m = \min_{e \in P} \{c(e)-f(e)\}\\
&4.\ \text{for each } e \in P,\ \text{increase } f(e) \text{ by } m\\
&5.\ \text{return } f
\end{aligned}
$$

*This algorithm can make a "mistake" which it can't undo*

## Ford-Fulkerson

**Idea**

- Like the naive algo. but it allows us to correct our mistakes
- At each iteration, we create an auxiliary graph that allows, at each edge, to either push more flow or "pushing flow back".
- Map flows in the auxiliary graph to flows in the actual graph

**Definition: Residual Network**

![[Pasted image 20260309140520.png]]

Let $G = (V,E)$, and let $f$ be a flow. The *residual network* $G_f = ( V, E_f )$ with
*capacity function* $c_f$ is defined as follows. For each $e = (u,v) \in E$:
- If $f(u, v) < c(u, v)$, add $e$ to $E_f$ with $c_f(u, v) = c(u, v) - f(u, v)$ “forward”
- If $f(u, v) > 0$: add the reserve of $e$ to $E_f$ with $c_f (v, u) = f(u, v)$ "backward"

**Definition: Augmenting Path**

Let $(G, c, s , t)$ be a flow network, let $f$ be a flow, let $G_f$ be the residual network. We say that a path $P$ in $G_f$ is an **augmenting path** if $P$ is a simple $s \rightarrow t$ path.
- Recall that a simple path means that no vertex appears more than once

**Definition: Augmenting a Flow**

Let $(G, c, s , t)$ be a flow network, let $f$ be a flow, let $G_f$ be the residual network, and let $P$ be an augmenting path in $G_f$. The procedure of **augmenting $f$ by $P$** creates a new $f^+$ from $f$ as follows:

For every $e' = (u, v) \in P$,
- if $e'$ is a forward edge, then increase $f(u, v)$ by $m$
- if $e'$ is a backward edge, then decrease $f(v, u)$ by $m$ 
where $m = min_{e' \in P} \{ c_{f}(e') \}$
### Proposition

Let $(G,c,s,t)$ be a flow network, let $f$ be a flow, let $G_f$ be the residual network, let $P$ be an augmenting path in $G_f$. Let $f^+$ be obtained when augmenting $f$ by $P$. Then:
1. $f^+$ is a flow in $G$
2. If $f$ had integer values, then $f^+$ has integer values and $⊽(f^+) \geq ⊽(f) + 1$

**Proof of 1.**

We start by showing that $f^+$ is a flow in $G$. 

To do this we must show that:
1. $f^+$ respects capacity constraints: $\forall e \in E, f^+(e) \leq c(e)$
2. $\forall v \in V \backslash \{ s, t \}, f^+_{out}(v) = f^+_{in}(v)$ 

$f^+$ respects capacity constraints because augmentation increases only by $m = min_{e' \in P} \{ c_{f}(e') \}$ where $c_f(e) = c(e) - f(e)$ for forward edges. Thus it must be the case that $f^+(e) \leq c(e)$ given that $f$ was a flow in $G$ 

As for 2.

Let $v \in V \backslash \{ s, t\}$ be arbitrary.

If $v \notin P$, it's flow has not been changed and the property holds trivially. 

Otherwise, since $P$ is a simple $s-t$ path in the residual network, we can say that for every vertex $v$ except $s,t$:
- one edge enters $v$
- one edge leaves $v$

We have 4 cases:
1. ...

**Proof of 2.**

Suppose $f$ had integer values. 

It will immediately follow that $f^+$ is integer valued if we can show that $m \geq 1$ is an integer . 

Recall that $m = \min \{ c_f(e) \}$ and $c_f$ is defined as follows: 
- For forward edges, $c_f(e) = c(e) - f(e)$
- For backward edges, $c_f(e) = f(e)$

Since $c_f(e)$ is clearly positive it is clear that $m \geq 1$

Since $c$ and $f$ are integer valued, their addition and subtraction will also be integer valued. 

To show that $⊽(f^+) \geq ⊽(f) + 1$:

The value changes according to the net flow out of s because s is the first vertex of the path, the path $P$ has an edge leaving $s$, but no edge entering $s$. 
    
Now check both possibilities for that first residual edge:
    
- if it is a forward residual edge $(s,v)$, then $f(s,v)$ increases by $m$
- if it is a backward residual edge $(s,v)$, that means $(v,s)$ is an original edge and $f(v,s)$ decreases by $m$

### Attempt 1: Pseudo-polynomial Time Impl.

$$
\begin{aligned}
&\text{Input } G, c, s, t\\
&f \equiv 0\\
&\text{while there is an augmenting path } P \text{ in the auxiliary graph } G_f:\\
&\quad m = \min_{e' \in P}\{c_f(e')\}\\
&\quad \text{for each } e'=(u,v)\in P:\\
&\qquad \text{if } e' \text{ is a forward edge, increase } f(u,v) \text{ by } m\\
&\qquad \text{else decrease } f(v,u) \text{ by } m\\
&\text{return } f
\end{aligned}
$$
Define $C = \sum_{e=(s,v)\in E} c(e)$ (the sum of capacities of edges leaving the source), then we make the claim that:

When $\sum_{e=(s,v)\in E} c(e) \leq C$, the FF algo. terminates after at most $C$ iterations of the "while" loop in L2.

## Cuts in Graphs

**Definition: $s-t$ cut**

A $s-t$ cut is a partition of $V$ into two sets $A, B$ such that $s \in A$ and $t \in B$.

**Definition: Capacity**

The capacity of $(A, B)$ is $c(A, B) = \sum_{\text{e outgoing from A}}c(e)$ 
### Min-cut-max-flow

**Proposition**

Let $(G,c,s,t)$ be a flow network, and let $f^{FF}$ be the flow returned by the
Ford-Fulkerson algorithm. 

Then, there is an $s-t$ cut $(A,B)$ such that $⊽(f^{FF}) = c(A,B)$

**Fact**

For every flow network $(G,c,s,t)$ and flow $f$ and $s-t$ cut $(A, B)$,
- $⊽(f) = \sum_{\text{e from A to B}}f(e) - \sum_{\text{e from B to A}}f(e)$   

In particular, $⊽(f) \leq c(A, B)$. 

We will prove this:

$$⊽(f) = \sum_{\text{e from A to B}}f(e) - \sum_{\text{e from B to A}}f(e)$$
$$\leq \sum_{\text{e from A to B}}f(e) = c(A, B)$$
### Attempt 2 of FF: Bucketing Implementation

- Start with augmenting paths that have a large capacity
- Let $G_f(w) =$ residual graph, removing edges with $c(e) < w$ 
- Augment via $G_f(C)$, then $G_f(C / 2)$ then $G_f(C / 4)$ etc.

$$
\begin{aligned}
\textbf{Input: } & G, c, s, t \\[4pt]
1.\;& f \equiv 0,\quad
w = \sum_{\text{e outgoing from s}}{c(e)}  \\[6pt]
2.\;& \textbf{while } w \ge 1: \\
3.\;& \quad \textbf{while there exists an augmenting path } P
\text{ in } G_f^{(w)}: \\
4.\;& \qquad \text{augment } f \text{ by } P \\
5.\;& \quad w \leftarrow \frac{w}{2} \\
6.\;& \textbf{return } f
\end{aligned}
$$
Has **TC**: $O( \log(|C|) ⋅ |E|^2 )$
#### Lemma 

After each iteration of the "while" loop, using value $w$ and yielding a flow $f$, there is an $s-t$ cut $(A, B)$, with capacity at most $⊽(f) + |E| \cdot w$
##### Proof

Define $A =\{ \text{vertices reachable from s in } G_f(w) \}$ and $B = V \backslash A$ 

WTS $c(A,B) = \sum_{\text{e outgoing from A}}c(e) \leq ⊽(f) + |E| \cdot w$ 

After an iteration of the "while" loop, there are no more augmenting paths $P$ in $G_f(w)$ that have capacity at least $w$. This means that there are no simple $s - t$ paths that have a bottleneck gte. $w$, by definition. 

Thus the capacity of the edges outgoing from A can be no larger than $w$.  
#### Corollary

At each iteration of the "while" loop there are at most $2 \dot |E|$ flow augmentation steps.

### Attempt 3: Edmonds-Karp Implementation of FF

**Input $G, c, s, t$**
$$
\begin{aligned}
1.\ &\text{let } f \equiv 0 \\
2.\ &\text{while BFS on } G_f \text{ finds a shortest augmenting path } P: \\
3.\ &\quad m = \min_{e' \in P} \{ c_f(e') \} \\
4.\ &\quad \text{for each } e' = (u,v) \in P: \\
5.\ &\qquad \text{if } e' \text{ is a forward edge increase } f(u,v) \text{ by } m \\
6.\ &\qquad \text{else decrease } f(v,u) \text{ by } m \\
7.\ &\text{return } f
\end{aligned}
$$
Has **TC: $O(|V||E^2|)$**

### Bipartite Matching

In a bipartite graph $G = (V = L \cup R, E)$ a **matching** $M \subseteq E$ is a set of edges such that no two edges touch the same vertex. A matching is perfect if $|M| = \min \{ |L|, |R| \}$

**Input**: A undirected bipartite graph  $G = (V = L \cup R, E)$.
**Output**: A matching $M \subseteq E$ such that $|M| = m^*$ where $m^* = \max_{\text{ matching } M' \subseteq E} \{ |M'| \}$ 

We can transform this into a flow / network problem. Given $G$, create $(G',c,s,t)$ by:

3. Adding the node $t$. Add edges $(r, t), \forall r \in R$ to $E'$.

## Chapter 7.7 Extensions to Max Flow

### Problem 1: Circulation with Demands

- Instead of a single $s$ & $t$, what if we had a set of $S$ sources generating flow and a set of $T$ sinks absorbing this flow.
- Instead of maximizing flow, imagine sources have fixed supply values and sinks have fixed demand values and our goal is ship flow from nodes with supply to those with demand.
	- "Satisfy the demand with the available supply"
#### Setup

- Given a flow network $G = (V, E)$ with capacities on the edges. 
- For each node $v \in V$ is a demand $d_v$.
	- If $d_v > 0$, this indicates that the node $v$ has a demand of $d_v$ for flow.
		- Meaning that the node is a sink, and it wishes to receive du units more flow than it sends out.
	- If $d_v < 0$, this indicates that $v$ has a supply of $-d_v$
		- The node is a source, and it wishes to send out $-d_v$ units more flow than it receives. 
	- If $d_v = 0$, then the node $v$ is neither a source nor a sink. We will assume that all capacities and demands are integers.

We use $S$ to denote the set of all nodes with negative demand and $T$ to denote the set of all nodes with positive demand.

We say that a circulation with demands $\{ d_v \}$ is a function $f$ that assigns a non-negative real number to each edge and satisfies the following two conditions:
1. **Capacity conditions:** For each $e \in E$, we have $0 \leq f(e) \leq c_e$.
2. **Demand conditions:** For each $v \in V$, we have $v$, $f^{in}(v) - f^{out}(v) = d_v$ 

### Building Up

**Theorem 7.49**

If there exists a feasible circulation with demands $\{ d_v \}$, then $\sum_v d_v = 0$.
- Suppose there exists a feasible circulation with demands $\{ d_v \}$. 
- So $\sum_v d_v = \sum_v f^{in}(v) - f^{out}(v)$
- Consider the value $f(e)$ for each edge $e = (u, v)$. It is counted exactly twice:
	- Once in $f^{out}(u)$ and once in $f^{in}(v)$ 
- Since this happens for each edge, they cancel out.

From **7.49**, we know that:
$$\sum_{v:d_v > 0}d_v = \sum_{v:d_v < 0}-d_v$$
Let $D$ denote this common value.

### Algo.

#### Idea

Attach a "super-source" $s*$ to each node in $S$, and a "super-sink" $t*$ to each node in $T$. 

To be specific:
1. Create a graph $G'$ from $G$ by adding new nodes $s*$ and $t*$ to $G$. 
2. For each node $v \in T$ (each node $v$ with $d_v > 0$) we add an edge $(v, t*)$ with capacity $d_v$. 
3. For each node $u \in S$ (each node with $d_v< 0$) we add an edge $(s*, u)$ with capacity $-d_v$. We carry the remaining structure of $G$ over to $G’$ unchanged.
