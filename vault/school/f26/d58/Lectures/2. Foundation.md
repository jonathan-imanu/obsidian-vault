## Application Protocol

**URL**: Uniform Resource Locater
**HTTP**: Hyper Text Transfer Protocol
**TCP**: Transmission Control Protocol

For a single URL request there are 17 total messages!

A protocol defines the interfaces between the layers in the same system and with the layers of the peer system.
- They are building blocks of a network architecture
## OSI 7-layers Model

OSI stands for Open Systems Interconnection

**Physical Layer**: Handles the transmission of raw bits over a communication link.

**Data Link Layer**: 
- Collects a stream of bits into a larger aggregate called a frame
- Network adaptor along with device driver in OS implement the protocol in this layer
- Frames are actually delivered to hosts

**Network Layer**: 
- Handles routing among nodes within a network that has packet switching
- Unit of data exchanged between nodes in this layer is called a *packet*
- The lower three layers are implemented on network nodes

**Transport Layer**:
- Process-to-process channel
- Unit of data is *message*

**Session Layer**
- Provides a name space that is used to tie together the potentially different transport streams that are part of a single application.

**Presentation Layer**
- Concerned about the format of data exchanged between peers

**Application Layer**
- Standardize common type of exchanges
- The transport layer and the higher layers typically run only on end hosts and not on the intermediate switches and routers

## Performance

### Bandwidth

The width of the frequency band. 

Measured by the bits per second (**Mbps**) that can be transmitted over a communication link.
- $10^6 \text{bits / second} = 2^{20} \text{bits / second}$

Latency = propagation + transmit + queue
Propagation = distance / speed of light
Transmit = size / bandwidth

Using this we can infer:

- One bit transmission $\rightarrow$ propagation is important
- Large bytes transmission $\rightarrow$ bandwidth is important

We view the channel between a pair of processes like a hollow pipe:

Link Capacity can be determined by the **Bandwidth Delay Product:** Bandwidth $\times$ Delay.
### Delay Bandwidth

The relative importance of bandwidth and latency depends on the application.
- For large file transfer, bandwidth is critical
- For smaller messages, latency is critical
