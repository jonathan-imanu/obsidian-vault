The dominant wired and wireless LAN technology. It is the first widely used LAN technology. It uses the *Manchester encoding scheme*.

**Carrier Sense**: Wait for link to be idle. If the channel is idle, start transmitting. Otherwise, wait until idle.

**Collision Detection**: Listen while transmitting. If a collision is detected, abort the transmission and send a jam signal.
- *Random Access:* Exponential back-off. After a collision, wait a random amount of time before trying again.

Uses **CSMA/CD** (Carrier Sense Multiple Access with Collision Detection).

This basically just means that Ethernet is a set of nodes that send and receive frames over a shared link where each node can:
- distinguish between a busy and idle link
- listen as it transmits so it can tell when a frame it transmits collides with some other frame

- **Ethernet segment:** A coaxial cable of up to 500 m
	- Hosts connect to a segment by tapping into it
- **Transceiver:** attached directly to the tap. It detects when the line is idle and drives signal when the host is transmitting.
	- Receives incoming signal. 
	- Connected to an Ethernet adapter that is plugged into the host
- **Adapter**: Implements the protocol

**Repeater**: A device that forwards digital signals. Multiple segments are joined together by repeaters.

Any signal placed on the Ethernet by a host is broadcast over the entire
network.
 - Signal is propagated in both directions.
 - Repeaters forward the signal on all outgoing segments.
 - Terminators attached to the end of each segment absorb the signal
### Limitations

 Latency depends on the physical length of link. If a collision is detected, the sender won't see it for $2 \times \text{ link latency}$ 
- *Maximum wire length is 2500 meters*
- *Maximum length of the packet is 512 bits (64 bytes)*
## Access Protocol for Ethernet

Algorithm is called Ethernet's **Media Access Control (MAC)**.
- It is implemented in Hardware on the network adaptor.
#### Frame format

![[Pasted image 20260929121059.png]]

- Preamble (64 bit): Allows the receiver to synchronize with the signal
- Host and Destination Address (48 bit each)
- Packet Type (16 bit)
- Data (up to 1500 bytes)
	- Frame must contain at least **46 bytes** of data so that it is long enough to detect collision
- CTC (32 bit)
	- Checked at receiver. Frame is dropped if an error is detected.
	- *No error correction just error detection.*

## Addresses

Each host on Ethernet has a unique Ethernet address (belonging to an adaptor not host).

**Unicast Address**: Identifies one specific L2 interface.
**Broadcast Address**: A special address consisting of all 1s is sent to everyone up to the host.
**Multicast Address**: Like broadcast but we can program an adaptor to indicate what group of hosts should receive frames.

# Physical Layer

## Repeaters

There is a distance limitation in LAN because electrical signal becomes weaker as it travels.

**Repeaters** join LANs together. They are an analog electronic device that monitors electrical signals and transmits an amplified copy.
## Hubs

Joins multiple input lines electrically. It is designed to hold multiple line cards. Do not necessarily amplify the signal.

### Limitations of Hubs & Repeaters

1. There becomes one large collision domain because every bit is sent everywhere 
2. Cannot support multiple LAN technologies
3. A limit on maximum nodes and distances
## Bridges

Connects two or more LANs at link layer. 
- Extracts destination address from the frame
- Looks up the destination in a table
- Forwards the frame to the appropriate LAN segment

Each segment becomes its own collision domain

A device that offers several advantages over hubs and repeaters (such as applying CS and CD) with the drawback of being more expensive machines that have a delay in forwarding frames (because they need to learn where to forward frames (*routing table*))
## Switches

Like a bridge but for hosts not LANS (typically)

**Cut-Through Switching**: Forward an ethernet frame as soon as we receive it rather than waiting for the whole thing like in store and forward.

To know where to send a frame, switches build a MAC address table. If we have a match in the table, use it. Otherwise, we send it to everyone (*flooding*). Use a TTL field in this table.

### The need for a Spanning Tree

**Problem**: In a network with redundancy, flooding can cause cycles!
- **Solution**: Build a spanning tree between nodes, frames can only be forwarded between nodes with an edge. 
****#### Algorithm

A distributed algorithm where all switches (nodes) in the network must elect a root. *The root is defined as the switch with the smallest identifier.* 

Initially, each switch advertises itself as root using messages `(rootID, distance, senderID)`. Switches update their advertisements as they learn better information, and the lowest-ID switch becomes root. Each non-root switch selects one root port providing its lowest-cost path to the root. On each link, the endpoint with the shorter distance to the root becomes designated for that link.
