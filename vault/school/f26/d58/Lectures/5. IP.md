#### Internetworking

An arbitrary collection of networks interconnected to provide some sort of host-host to packet delivery service.
- IP is a tool that runs on all the nodes in a collection of networks that defines the infrastructure through which these nodes and networks can function as an internetwork.
# Internet Protocol (IP)

Layer 3 within the OSI model.

IP has the following characteristics:
1. Connectionless
2. Unreliable
3. Best effort
4. Datagram

A **datagram** is the basic unit of information passed across an internetwork using **IP**.

### Fragmentation

**Maximum Transmission Unit (MTU)**: The largest size (in bytes) of a data packet or frame that can be sent across a network.

**Fragmentation**: When a router receives a datagram that it wants to forward over the network such that $bytes(datagram) > MTU$ of the outgoing link(s).

**Solution 1**: The router fragments the IP datagram into multiple, self-contained datagrams. These fragments are only reassembled at the destination host not intermediate routers.
- To avoid fragmentation, use path MTU discovery to find the smallest MTU along the path.

## IP Datagram Forwarding

The process a router uses to move an IP packet, also called an IP datagram, from one network interface to another so it can get closer to its destination.

A router tries in order based on the network number of the destination:
1. Delivering packet to connected interface if network number matches
2. Delivering packet to NextHop if included in forwarding table
3. Deliver packet to default router otherwise

## Addresses

Globally unique and hierarchical.

- 32 bits long

5 classes originally but these were too rigid. This rigidity led to an inefficient use of address space, and a shortage of addresses.

### Subnetting

Allows the flow of network traffic between hosts to be segregated based on network configuration. By organizing hosts into logical groups, subnetting can improve network security and performance.
- **Subnet Mask**: Same format as IP (4 bytes). Applying the subnet mask to an IP address splits the address into two parts:
	1. An extended network address with contains bits for the subnet identifier
	2. A host address

### Classless Inter-Domain Routing (CIDR)

Addresses two scaling concerns in the Internet;
1. The growth of backbone routing table as more and more network numbers need to be stored in them
2. Exhaustion on the 32-bit address space
	1. Caused because of address assignment efficiency. If a network needs 2 hosts, we would need a Class C address which has 256 addresses.

**CIDR Prefix:** X/Y where X is the fixed part belonging to a singular network. X (the prefix) can be of any length (unlike the class-based IP system). 
- Routes route based on these prefixes rather than storing one route for every individual host.
#### Address Resolution Protocol (ARP)

- Map IP addresses into physical addresses using a table. Broadcast the request if a table miss.
## DNS: Domain Naming System

DNS maintains a hierarchal, distributed database of names. Servers are arranged in a hierarchy where each domain has a root server. An application needing an IP address is a DNS client.
