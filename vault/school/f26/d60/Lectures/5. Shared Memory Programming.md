**Idea**: A singular blob of memory with multiple cores acting on it. Coordination is done through memory rather than by messages.

**Shared Memory Languages**:
- **pthreads**: POSIX threads, heavyweight, lower level and more clumsy
- **PGAS languages**: Partition Global Address Space UPC, Titanium, Co-Array Fortran
- **OPenMP**: An API shared memory parallel programming
# OpenMP

A set of compiler directives inserted in the source program.
- Pragmas in C/C++

Thread based parallelism with a fork-join model.
