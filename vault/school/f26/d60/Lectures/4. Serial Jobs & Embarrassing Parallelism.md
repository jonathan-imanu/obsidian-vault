pretending there are twice as many logical cores than real ones.

**Home is readonly in most supercomputers.** Remember to do module loads in `sbatch` scripts!

Useful environment variables in `sbatch` submission scripts:
- `SLURM_SUBMIT_DIR`
- `SLURM_TASK_PER_NODE`: Useful for telling GNU parallel how many jobs to run.
## GNU Parallel

A terminal tool to parallelize processes. Great for running blocks of serial subjobs.
### Examples

```bash
# Basic
parallel -j 2 ./analyze {} ::: sample1.csv sample2.csv sample3.csv
# All combinations. Use --link for matching pairs.
parallel --dry-run ./simulate --size {1} --seed {2} ::: 100 200 ::: 7 8 9
# Basic pipe example where we read from stdin
seq 1 10 | parallel cmd {}
```

## RAMDisk

Copy input files to fast, temporary storage on a compute node, run the jobs there, and copy the results back before the job ends.


```bash
#SLURM Preamble

# Copy input files to fast compute node
mkdir /dev/shm/$USER/workdir
cp $SLURM_SUBMIT_DIR/* /dev/shm/$USER/workdir
cd /dev/shm/$USER/workdir

# Run the actual job...

# Copy data back
tar cf $SLURM_SUBMIT_DIR/out.tar *.out
```
