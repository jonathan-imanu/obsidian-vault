$throughput = H = \frac{N}{T}$ where $N$ is number of tasks and $T$ is the total time.

If the tasks are independent and we have $P$ processors, $H$ can be increased by a factor of $P$. 

We say something is *"embarrassingly parallel"* or *perfect scaling* if the relationship with processor number and tasks per unit time is linear ($H \propto P$)

For most cases, the processing can be split up but are not completely parallelizable:

**Speedup**: How much faster the problem is solved as processor number increases.
- This measures by the serial time divided by parallel times

$S = \frac{T_{serial}}{T(P)}$
- For embarrassingly parallel applications, $S \propto P$ is a linear speed-up.

**Efficiency**: $E =\frac{S}{P}$

### Amdahl's Law

**Program speedup is limited by the part that cannot be parallelized.** Gives the upper limit of speedup for a *problem of fixed size*. 

$f = \frac{T_s}{T_s + NT_1}$ is the serial fraction of the application.

$S=\frac{1}{f+\frac{1-f}{P}}$
- $f$ is the fraction that must be ran serially and $1- f$ is the fraction that can run in parallel
- $P$ is the number of processors

As $P \rightarrow \infty, S \rightarrow \frac{1}{f}$. So the serial part, *dominates asymptotically*.

#### Lecture Derivation

Given $S = \frac{T_{serial}}{T(P)}$, we can say that $T_{serial} = NT_1 + T_{s}$ where $NT_1$ is the part that could become parallelizable ($N$ repeated tasks) and $T_{s}$ is the part that must be done serially. 

Following this, given $P$ processors, we can represent $T(P)$ as:
$$T(P) = \frac{NT_1}{P} + T_S$$ 
So $f = \frac{T_s}{T_s + NT_1}$ is the serial fraction of the application.
### Gustafson's Law

In reality, the sizes of problems scale with the amount of available resources. Approx. parallel part scales linearly with the amount of resources, and the serial part does not increase with respect to the size of the problem,
$$S = s + pN$$
- $s$: The fraction of the parallel run's time done doing sequential work
- $p$: The fraction of the parallel run's time spent on the parallel part
- $S$: How long the same, enlarged problem would take on one processor

$S_G = f + p(1-f)$ where $f$ is the sequential fraction and $1-f$ is the parallel fraction.

> This is called weak scaling, where the scaled speedup is calculated based on the amount of work done for a **scaled problem size**

- **Strong scaling** is defined as how the solution time varies with the number of processors for a fixed total problem size.
	- $E_{\text{strong}}=\frac{T_1/P}{T_P}\times100\%$
- **Weak scaling** is defined as how the solution time varies with the number of processors for a fixed problem size per processor.
	- $E_{\text{weak}}=\frac{T_1}{T_P}\times100\%$

> **Gustafson’s Law asks: “If I add processors, how much bigger a problem can I solve in roughly the same time?”** Amdahl asks how much faster you can solve the same problem.
