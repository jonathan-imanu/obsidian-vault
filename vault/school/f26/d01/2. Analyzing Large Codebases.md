## What is Apache Superset?

A OSS modern data exploration and visualization platform. It is a BI platform that:
- Connects to data sources
- Enables data engineers to create dashboards from these sources
- Make those dashboards available to technical and non-technical users

Superset is a **monorepo** (all related modules are stored here). The backend is a Flask server designed as a *Layered Architecture Style*.
### Layered Architecture Style

The idea is that we can separate the code by its overall theme. Model View Controller (**MVC**) is an example.
### Microkernel Architecture Style

Superset uses this architecture to connect to arbitrary data sources. This also called **plug-in architecture.**

A small, stable core provides the fundamental execution/coordination mechanism, while most functionality lives in independently developed plug-ins/extensions.
- The core system is **NOT** dependent on a specific plugin to work
- Plugins communicate to the core system using a defined contract
