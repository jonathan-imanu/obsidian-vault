## Licensing

GPL is a license that requires you to open-source all modifications. This is known as a viral licensing (or Copyleft) model. 
- Viral because `License A + Copyleft = Copyleft`
- Other examples include `License A`

The other type of licenses within OSS are permissive licenses that allow us to use project contents with no obligation to OSS modifications. These licenses are highly compatible with other software bases.
- `License A + Permissive = License A`
- Examples include MIT, BSD, Apache
